Read the full [PROTOCOL.md](PROTOCOL.md) as a reference file before any n8n action. It contains the shared routing rules and MCP tool reference.

Where the protocol says to use the Skill tool, read the matching installed skill's `SKILL.md` with the available file reader. Set `IsSkillFile: true` if that reader supports it. Read linked references when their conditions apply. After compaction, reload the protocol and the skills required for the next action.
